How to use this (first time here? start here)
  1. Parameters: enter Diet coordinates, tribe, and merchant bonus. Set max route spread.
  2. Open Village overview → Overview in Travian, copy the whole page, paste it into Paste village information, click Parse villages.
  3. Open Village overview → Resources → Production, copy the whole page, paste it into the same box, click Parse villages again.
  4. In Trade office levels, set the default level, then fix any village that differs. Check the Crop surplus/hour column.
  5. Set one village's Role to Source if it should feed the others. Otherwise leave all roles at "—".
  6. Click Generate routes.
  7. Copy link to save or share the setup.

Opened a shared link? Villages are already loaded — skip steps 2–3. Clear villages empties the table.
