How to use this (first time here? start here)

1. Parameters

Open Parameters. Set the Diet village coordinates (the village you're feeding crop into), your player tribe, and your alliance's Merchant bonus if it has one. Leave Max route spread at "Hourly" unless a village is too far to route hourly, or you want bigger, less frequent convoys.

2. Load your villages (two pastes, same box)

The two things this tool needs — how many merchants each village has, and how much crop each village produces — live on different Travian pages, so you paste them one after the other. Each Parse villages merges into the table by village name; it only fills in the fields that paste actually contains, so the order doesn't matter and nothing gets overwritten.

  • Village overview → Overview — the page listing each village with its available merchants (the x/y merchant column). This gives village names, merchant counts, and usually coordinates.
  • Resource production overview (Village overview → Resources → Production) — the table where each village row ends with its hourly crop production. This fills in Crop surplus/hour.

Paste one, click Parse villages, paste the other, click it again. Copy the whole page each time — extra text is ignored. Village groups / coordinate lists on either page are picked up automatically. Clear villages wipes the table to start over. Skip this whole step if you opened a shared link with villages already built in.

3. Check the table

Open Trade office levels. Set a Default level to apply it to every village at once; editing a single village's level (or any other cell) detaches that village so later default changes leave it alone.

Crop surplus/hour is how much crop the village can spare on top of its own consumption — the production paste fills this in, but check it and adjust. A village at 0 sends nothing.

If one strong village should push its crop out through your other villages before it reaches Diet, set its Role to Source. Leave every role at "—" if each village just sends straight to Diet on its own.

4. Generate routes

Click Generate routes. Each row is one recurring merchant route: from, to, crop per shipment (merchants per firing in brackets), how often it fires (every 1/2/3/4/6/8h), and its departure / arrival minute. Arrivals at Diet are spread so every hour of the cycle gets a delivery of roughly even size, even when a single route only fires every few hours.

5. Read the warnings

They tell you where the plan is constrained:

  • "can only ship X of Y crop/hour to Diet" — the village produces more than its own merchants can carry that distance; the rest stays put. Raise its trade office level, add merchants, or shorten the distance.
  • "can't route any to Diet (no merchants or too far)" — usually means you haven't pasted the merchant page for that village yet.
  • relay skipped — too far / too costly in merchants — the source can't sustain a route to it within the fleet it has.
  • "couldn't be allocated" — leftover source crop that no relay or hub had capacity to take.

6. Save it

Copy link stores your entire setup — villages included — in the URL. Opening that link restores everything without pasting anything back in.
